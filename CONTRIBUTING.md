# Contributing

Contributions should preserve the project's research reproducibility and defensive scope.

Before opening a pull request:

1. run `python3 -m pytest -q`;
2. run `python3 run_all.py --demo --quick`;
3. document any methodological change in the README or experiment report;
4. do not commit raw third-party datasets, credentials, virtual environments, or large generated model files.

For research changes, include the motivation, experimental setup, evaluation metrics, and limitations.

# Security and Responsible Use

This repository is a **defensive, offline research prototype** for machine-learning-based network intrusion detection.

It is intended for:

- public cybersecurity datasets;
- controlled experiments;
- reproducible academic research;
- defensive model evaluation.

It is **not** a live packet-capture engine, intrusion-prevention system, or authorization mechanism. Do not use the code to inspect, scan, interfere with, or attack systems without explicit authorization.

For a security issue in the code, open a private report through the repository's configured GitHub security mechanism when available.
